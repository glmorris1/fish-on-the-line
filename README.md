# Fish on the Line

Landing page and production artwork for the Fish on the Line challenge coin.

The QR artwork resolves to `https://glmorris1.github.io/fish-on-the-line/`.

## Files

- `index.html`, `styles.css` — GitHub Pages landing page
- `assets/fish-qr.png` — high-resolution production QR artwork
- `assets/fish-qr.svg` — scalable master artwork
- `assets/fish-coin-mockup.png` — presentation mockup
